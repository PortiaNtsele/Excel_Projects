# 📊 Retail Sales Analysis Project

This project analyzes retail sales data (2009–2011) using Excel to identify trends, performance, and business insights.

---

## 📁 Project Structure
- data → Raw dataset  
- analysis → Pivot tables, KPIs, and cleaned outputs  
- dashboard → Final Excel dashboard  
- screenshots → Visual outputs  

---

## 📊 Key Metrics
- Total Sales  
- Total Orders  
- Total Quantity  
- Average Order Value (AOV)  

---

## 🧠 Key Insights
- Revenue is heavily concentrated in the United Kingdom  
- Sales show strong seasonality with peaks in March and December  
- Customer purchasing behavior is stable across time  

---

## 🎯 Purpose
This project demonstrates end-to-end Excel data analysis and dashboard creation skills.
