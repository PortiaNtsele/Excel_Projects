# Retail Sales Dashboard (2009–2011)

## 📊 Overview
This project analyzes retail transaction data to identify sales trends, market performance, and customer behavior.

## 🧰 Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables

## 📈 Dashboard Features
- KPI cards (Sales, Orders, Quantity, AOV)
- Monthly trend analysis
- Country-level analysis
- Interactive slicers (Country, Month)

## 🧠 Key Insights & Recommendations
Revenue is highly concentrated in the United Kingdom, indicating reliance on a single core market. Sales show strong seasonality, with peaks in March and December. Expanding international markets and aligning strategies with seasonal demand can improve growth and reduce dependency.
